# ⛳ GolfOS

The modern open-source platform for golf tournaments, live scoring, leaderboards and player statistics.

## Features

- 🏌️ Tournament management
- 📱 Live scoring
- 📊 Live leaderboard
- 👥 Player management
- 📄 PDF results
- 📈 Statistics
